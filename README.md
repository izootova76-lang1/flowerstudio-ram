# Flower Studio

Сайт для цветочной студии **Flower Studio** в Раменском.

Проект создан как полноценный учебно-практический кейс: от структуры и визуальной концепции до адаптивной версии и публикации.

## Что есть на сайте

* главная страница
* каталог
* комнатные растения
* воздушные шары
* сборка букета
* корзина
* доставка
* FAQ
* отзывы
* контакты
* политика конфиденциальности
* оферта

## Особенности проекта

* адаптивная вёрстка для мобильных устройств
* навигация по разделам
* поиск и фильтры
* формы и интерактивные элементы
* рабочие контакты
* проверка мобильных сценариев
* публикация через GitHub Pages

## Технологии

* JavaScript
* Git
* GitHub Pages
* Cursor
* Lovable
